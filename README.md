# Xiang Kang apparel — integrated review website

Separate public review website bringing together the existing kidswear and active/casualwear ranges. The original websites are unchanged.

- `/`: shared range selector
- `/kids/`: children’s apparel site, including all original subpages
- `/active/`: activewear and casualwear site, including filters and enquiry briefs

All links and assets are relative so the site works under the GitHub Pages project path. Email enquiry forms prepare drafts only; they do not submit or store enquiries. Contact: besttom23@gmail.com.

Photography, customer sample provenance, brand attribution and AI concept labels are preserved from the source sites. Customer artwork is not offered for reproduction or resale. All rights reserved.

Hosted on GitHub Pages from `main`, repository root. Static HTML, CSS and JavaScript; no build step.
